Lección 3: Carga y Almacenamiento en Memoria (Load y Store)

Aarch64 utiliza una arquitectura llamada Load/Store. Esto significa que las instrucciones aritméticas solo funcionan entre registros. Para interactuar con la memoria RAM, dependemos exclusivamente de dos comandos fundamentales.

1. Las 2 Instrucciones de Memoria

A diferencia de otras arquitecturas, aquí dividimos la lectura y la escritura de forma estricta:

  1. LDR (Load Register): Lee un dato desde una dirección de memoria RAM y lo trae hacia un registro del procesador.
    Sintaxis básica: LDR Xd, [Xn]
  2. STR (Store Register): Toma un dato que ya está dentro de un registro y lo guarda en una dirección de la memoria RAM.
    Sintaxis básica: STR Xt, [Xn]

2. El uso de los Corchetes

En Aarch64, los corchetes actúan como los punteros. Indican que el registro de adentro no contiene un número común, sino una dirección de memoria física.

  • MOV X0, X1: Copia el valor del registro X1 directamente dentro del registro X0.
  • LDR X0, [X1]: Va a la dirección de la memoria RAM que apunta X1, lee lo que hay allí y lo mete en X0.

3. Modos de Direccionamiento Comunes

Para movernos a través de arreglos o variables en memoria de manera ordenada, usamos estas tres variantes de sintaxis:

  • Desplazamiento Inmediato (Offset): Accede a una dirección sumando un número de bytes sin modificar el registro base.
    LDR X0, [X1, #8] (Lee la dirección X1 + 8 bytes).
  • Pre-indexado (Pre-indexed): Suma el desplazamiento al registro base primero, accede a la memoria y actualiza el registro base automáticamente.
    LDR X0, [X1, #8]! (El signo de exclamación indica que X1 cambia su valor).
  • Post-indexado (Post-indexed): Accede primero a la dirección actual del registro base, y después de leer o escribir, le suma el desplazamiento.
    LDR X0, [X1], #8 (Lee X1, y luego X1 aumenta en 8).

4. Ejemplo Práctico Estructurado

Analiza cómo se combinan las instrucciones de las lecciones anteriores con el manejo de memoria:


// X1 contiene la dirección de memoria de un número (ejemplo: 100)
// X2 contiene la dirección de memoria donde guardaremos el resultado

LDR X9, [X1]         ; 1. Traemos el valor desde la RAM (X9 ahora tiene el número 100)
ADD X9, X9, #50      ; 2. Modificamos el dato de forma segura (100 + 50 = 150)
STR X9, [X2]         ; 3. Guardamos el nuevo valor (150) de vuelta en la RAM
