Lección 4: Comparaciones, Etiquetas y Saltos (Branches)

El control de flujo en Aarch64 se realiza en dos pasos estrictos: primero se realiza una operación matemática que altera las banderas (flags) del procesador en el registro de estado (NZCV), y luego se ejecuta un salto condicional basado en esas banderas.

1. Las Etiquetas (Labels)

Una etiqueta es una palabra que tú inventas seguida de dos puntos (:). Sirve para marcar una dirección de memoria en el código a la cual el procesador puede saltar directamente.

mi_etiqueta:
    MOV X0, #5    ; El código continúa aquí después de un salto

2. La Instrucción de Comparación: CMP

La instrucción CMP (Compare) resta el segundo operando del primero (Xn - Xm). El procesador descarta el resultado numérico, pero actualiza las banderas de estado:

  • N (Negative): Se activa si el resultado es negativo.
  • Z (Zero): Se activa si el resultado es cero (significa que ambos números eran iguales).
  • C (Carry): Se activa si ocurre un acarreo aritmético.
  • V (Overflow): Se activa si ocurre un desbordamiento numérico.

Sintaxis: CMP Xn, Xm o CMP Xn, #inmediato

3. Instrucciones de Salto (Branches)

Existen saltos incondicionales (saltar siempre) y saltos condicionales (saltar solo si se cumple una regla de la comparación previa):

  1. B (Branch): Salto incondicional. Obliga al procesador a ir a la etiqueta indicada sin importar nada.
    Sintaxis: B etiqueta
  2. B.EQ (Branch if Equal): Salta a la etiqueta si los dos números comparados con CMP eran exactamente iguales (si la bandera Z es 1).
  3. B.NE (Branch if Not Equal): Salta a la etiqueta si los números comparados eran diferentes (si la bandera Z es 0).
  4. B.GT (Branch if Greater Than): Salta si el primer número era estrictamente mayor que el segundo (para números con signo).
  5. B.LT (Branch if Less Than): Salta si el primer número era estrictamente menor que el segundo (para números con signo).

4. Ejemplo Práctico Estructurado (Simulación de un IF / ELSE)

Analiza cómo estructurar una condición para verificar si el contenido de un registro es igual a 10:


// X9 contiene un número que queremos validar (por ejemplo, el número 10)

CMP X9, #10          ; 1. Comparamos el valor de X9 con el número 10
B.NE es_diferente    ; 2. Si NO son iguales, salta a la etiqueta 'es_diferente'

// --- Bloque IF: Se ejecuta SOLO si X9 es exactamente 10 ---
MOV X0, #1           ; Código que se ejecuta si es igual
B fin_condicion      ; Saltamos al final para evitar entrar al bloque del ELSE

es_diferente:
// --- Bloque ELSE: Se ejecuta SOLO si X9 NO es 10 ---
    MOV X0, #0       ; Código que se ejecuta si es diferente

fin_condicion:
    ; El programa continúa su ejecución normal aquí
